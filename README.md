# Preethi A R — Portfolio

Personal portfolio of Preethi A R, an aspiring QA engineer and software developer from Bengaluru, India.

A single static page (`index.html`) with no build step. It includes:

- Projects with links to their GitHub repositories, filterable by category and skill
- A playground with a mini task-manager app, a demo test run and an interactive terminal
- Dark / light themes and several colour moods
- A contact form that opens Gmail, Outlook.com or the visitor's email app

## Run locally

Open `index.html` in any browser.
